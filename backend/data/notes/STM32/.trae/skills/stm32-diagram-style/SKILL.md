# STM32 笔记配图绘制风格规范

本 SKILL 定义了 STM32 学习笔记中所有配图的统一绘制风格。任何新增的配图（框图、流程图、对比图、类比图、结构图等）**必须**严格遵循本规范，保持和已有图片风格一致。

---

## 一、总览

笔记中已有的图片（如 `11.3/中断结构框图.jpg`、`11.4/时钟树.jpg`、`10.22/推挽输出电路结构.jpg` 等）遵循统一的视觉风格：

| 特征 | 描述 |
| --- | --- |
| **整体风格** | 扁平化、教学示意风格，类似教科书插图，非 3D 渲染 |
| **背景** | 白色或浅色纯色背景，干净无纹理 |
| **文字** | 全部使用中文标注，字体清晰统一（黑体/微软雅黑风格） |
| **形状** | 主要使用圆角矩形方块 + 直线/折线/箭头连接 |
| **配色** | 颜色统一、克制，每种颜色有固定含义 |

---

## 二、配色规范

所有配图使用以下统一配色体系，**不得随意引入新颜色**：

| 颜色 | 用途 | 示例 |
| --- | --- | --- |
| **灰色底色** | 表示该模块处于**关闭/默认禁用**状态 | 时钟树初始状态中的关闭外设 |
| **绿色底色** | 表示该模块处于**开启/默认启用**状态 | 时钟树初始状态中已开启的模块 |
| **红色** | **重点标注/高亮**，用于圈出或标红关键区域 | 总线与时钟树对应图中的红色标注线 |
| **蓝色** | 一般性模块框、数据通路 | 框图模块的边框或填充 |
| **黑色/深灰** | 普通文字标注、连线、箭头 | 所有文字标签和连接线 |

### 配色原则

- 颜色服务于信息传达，不是装饰，**不要使用过多颜色**
- 同一张图中，每种颜色只表达一种含义
- 状态类信息（开/关、禁用/启用）用灰色/绿色区分
- 重点强调用红色，普通内容用蓝色或黑色

## 三、形状与布局规范

### 3.1 模块框

- 使用**圆角矩形**表示模块、组件、寄存器
- 框内写中文标签说明该模块名称
- 同类模块框大小尽量一致，整齐对齐

### 3.2 连接线

- 数据通路用**实线箭头**，表示数据流向
- 控制信号可适当用虚线或不同线型区分
- 折线拐角处用直角转弯，不出现斜线
- 箭头明确指向目标方向，不产生歧义

### 3.3 布局

- **从左到右、从上到下**的信息流向
- 同一层级模块水平排列，上下级模块垂直排列
- 左右分栏布局适用于对比展示（如左侧模块整体、右侧内部结构）
- 框与框之间留有适当间距，不拥挤

---

## 四、文字标注规范

- **全部使用中文**，不用英文缩写（除非是寄存器名如 PSC、ARR、CNT 等固定术语）
- 模块名称放在框内居中
- 连接线旁可标注小字说明该路径的含义（如「8MHz」「×9」）
- 对齐方式：类似层级/同一行的文字统一对齐

---

## 五、常见图类型及画法

### 5.1 框图（Block Diagram）

如 `中断结构框图.jpg`、`SPI内部模块图.jpg`、`USART模块.jpg`

- 用圆角矩形框表示各个模块
- 用箭头连接表示数据流或信号流
- 整体布局从左到右，表示「输入 → 处理 → 输出」的流程
- 如内容较多，可分左右两栏（左：整体，右：局部放大）

**示例结构**：
```
[模块A] ──→ [模块B] ──→ [模块C]
                ↓
           [模块D]
```

### 5.2 树形结构图

如 `时钟树.jpg`、`时钟树的初始状态.jpg`

- 从顶部（树根）向下展开，逐层分叉
- 同一层模块水平排列
- 用灰色/绿色底色区分状态
- 关键分叉点标注倍频系数或分频系数

### 5.3 类比图

如 `EXTI类比图.jpg`、`时钟类比图.jpg`、`树干对比.jpg`

- 左侧放实物/生活场景的示意图，右侧放对应的 STM32 概念图
- 用箭头连接左右对应的部分
- 图下方（或右方）可用简短文字标注类比关系

**示例结构**：
```
[生活实物图] ←→ [STM32概念图]
       │              │
    文字解释      文字标注
```

### 5.4 对比图

如 `推挽输出电路结构.jpg`、`不同的SPI通信方向.jpg`

- 多张子图水平或垂直并排排列
- 每张子图上方或下方标注子图标题
- 对比差异处可用红色高亮或圈出

### 5.5 电路结构图

如 `推挽输出电路结构.jpg`

- 用简洁的电路符号（MOS管、电阻、电源等）绘制
- 关键路径用红色或加粗线条标出
- 标注电流方向和电压节点

## 六、画图工具建议

| 工具 | 适用场景 |
| --- | --- |
| **PPT / WPS 演示** | 最推荐——圆角矩形 + 箭头 + 文本框，简单快捷，你的大部分配图就是 PPT 画的 |
| **Draw.io** | 流程图、结构框图，支持导出 JPG |
| **Visio** | 专业框图，但学习成本较高 |

---

## 七、画图检查清单

完成后逐项检查：

- [ ] 所有文字是否清晰可读（导出分辨率 ≥ 1920×1080）
- [ ] 颜色是否遵循配色规范（灰=关、绿=开、红=标注）
- [ ] 箭头方向是否清晰、无歧义
- [ ] 布局是否整齐对齐、无重叠
- [ ] 中文标注是否正确、无错别字
- [ ] 保存为 JPG 格式，放入对应日期文件夹
