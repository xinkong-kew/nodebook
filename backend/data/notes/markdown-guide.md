# Markdown 速查

## 标题

用 `#` 的数量表示层级，`#` 是一级标题。

## 强调

- **加粗**：`**文字**`
- *斜体*：`*文字*`
- ~~删除线~~：`~~文字~~`

## 列表

- 无序列表：`- 内容`
1. 有序列表：`1. 内容`

## 代码

行内代码：`npm run dev`

代码块：

```js
console.log('Hello, Notes!');
```
